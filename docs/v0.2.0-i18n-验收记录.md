# v0.2.0 多语言测试分支验收记录

日期：2026-08-13

分支：`codex/i18n-language-settings`

基线：`75ec1e1125a03e2239a2df74c151b4aebef76be7`

## 实施范围

- 首版支持 `system`、`zh-CN`、`en-US`，静态词典随主进程和 renderer 打包，不在线加载语言包。
- 新数据库默认跟随系统，升级数据库保持简体中文；非法偏好回退并修复为简体中文。
- 软件设置分为“常规 / AI 服务”，语言切换即时更新界面、窗口标题、`html lang/dir`、日期和数字。
- 诊断、扫描状态、操作历史、主进程消息和验证错误使用稳定翻译键；Skill 内容、路径、备注和自定义标签不改写。
- AI 分析记录 `outputLocale`，语言进入缓存键；旧记录迁移为 `zh-CN`，详情优先显示当前界面语言的结果。

## 隔离边界

- Electron E2E、Squirrel 维护启动与 packaged smoke 均使用系统临时目录中的独立 `SKILL_WORKBENCH_USER_DATA`。
- 测试没有安装 Squirrel 包，没有写入正式用户数据库，也没有覆盖已安装版本。
- 所有产物仅保存在当前工作区的 `out` 目录；分支未推送、未创建 PR、未合并 `main`。
